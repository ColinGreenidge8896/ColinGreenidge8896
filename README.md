## Selected Projects

**[Order Orchestration Service](https://github.com/glaslan/order-orchestration)** — Spring Boot
A 5-team enterprise simulation built collaboratively for an Enterprise Systems course. I worked on the Order Orchestration service, building JWT-authenticated REST endpoints and inventory claiming logic that reserves stock atomically across concurrent requests. Containerized via Docker Compose with GitHub Actions CI.

**[Personal Site](https://github.com/ColinGreenidge8896/PersonalSite)** — React + Vite + TypeScript
This site (linked above), self-hosted on a Raspberry Pi behind Tailscale Funnel with a Let's Encrypt cert. No cloud, no CDN — just a Pi and a public hostname.

**[Robot Control Network Interface](https://github.com/ColinGreenidge8896/NetworksV2TermProject)** — C++
A cross-platform TCP/UDP socket library with a binary packet protocol and built-in HTTP server. Communicates with a robot simulator over both transport protocols, packaged in Docker for Linux builds.

**[GhostBusters Backend](https://github.com/ColinGreenidge8896/Project5Database)** — Node.js + Express + MySQL
Led the database module for a multi-team enterprise simulation. Designed the normalized schema with input validation, built REST endpoints with transaction handling, and set up Docker-based deployment for dev and prod.
